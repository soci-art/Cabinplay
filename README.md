# CabinPlay

我的车是 2024 款长安 UNI-V，车机只有 HiCar 和 CarLink，没有 CarPlay，手机又是 iPhone。这个 App 就是为了解决这件事：让 iPhone 的 CarPlay 能显示到车机屏上，触控、音乐都走车机。

做法是两头拼起来：先在 iPhone 本机把 CarPlay 跑起来，再通过 CarLink（ICCOA/UCar）链路把画面送上车机。目前只在 UNI-V 上实车用过，其他同样是 CarLink 的车机理论上也能接，但没试过，不敢打包票。

现在能用的：

- 蓝牙找到车机，第一次输一次车机屏上的配对码，之后就不用再输了
- CarPlay 画面上屏，触控回传
- 音乐从车机喇叭出声
- 画质（自动 / 1080p / 720p / 480p）和帧率（60 / 30）可以在设置里调
- 设置里能检查更新，有新版会给出发行页

几个实话：

- 电话和微信语音走不了车机，还是在手机上接听——CarLink 这条链路拿不到车机麦克风
- 车机的播放/暂停键暂时没作用，上一首、下一首是好的
- 用的时候 App 要留在前台，划掉就断了

安装：从发行版下未签名的 IPA，用自己的付费证书签名后装。免费 Apple ID 签不了，不要白费功夫。
